## Mes données sont-elles envoyées quelque part ?

Non. Nokori n’a pas de compte, pas de serveur et ne se connecte à aucune banque. Sur téléphone, tout reste dans une base chiffrée sur l’appareil. Dans la version web, tout reste dans votre navigateur.

## J’ai changé de téléphone : comment retrouver mes données ?

Avec la sauvegarde chiffrée. Sur l’ancien téléphone : Réglages › Sauvegarde et restauration › Créer une sauvegarde, puis rangez le fichier (iCloud Drive, Google Drive, e-mail à vous-même…). Sur le nouveau : installez Nokori, touchez « J’ai déjà une sauvegarde Nokori », choisissez le fichier et entrez votre phrase secrète.

## J’ai oublié ma phrase secrète.

Personne ne peut ouvrir la sauvegarde sans elle, pas même nous : c’est ce qui la protège. Créez une nouvelle sauvegarde depuis le téléphone qui a encore vos données.

## Comment tout effacer ?

Réglages › Supprimer toutes mes données. Désinstaller l’app efface aussi tout. Les fichiers de sauvegarde que vous avez rangés vous-même ne sont pas touchés.

## Le verrouillage Face ID ne s’active pas.

Vérifiez que Face ID, Touch ID ou une empreinte est configuré dans les réglages du téléphone, puis réessayez dans Réglages › Verrouillage Face ID. Le verrouillage n’existe pas dans la version web.

## Je ne reçois pas les rappels avant les prélèvements.

Activez « Avant chaque prélèvement » dans Réglages, puis autorisez les notifications de Nokori dans les réglages du téléphone. Les rappels arrivent à 9 h, trois jours avant chaque charge, sans montant.

## Nokori déplace-t-il de l’argent ?

Jamais. Nokori est un carnet de comptes : « épargne prévue » signifie ce que vous avez prévu de mettre de côté vous-même, dans votre banque.
