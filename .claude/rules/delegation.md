# Règle de délégation

Délègue de toi-même, à chaque session, sans attendre qu'on te le demande.

- Collecte volumineuse → délègue :
  - texte des pages web et recherches simples → haiku-collecte ;
  - extraction de code et recherches croisées → sonnet-recherche ;
  - en parallèle quand les tâches sont indépendantes.
- Petite recherche (un fichier, une page) → fais-la toi-même : c'est moins cher.
- Réfléchir, résumer, interpréter, comparer, décider, écrire du code → garde-le pour toi.
- Ce que les agents renvoient, ce sont des matériaux bruts, jamais ta réponse finale.
  Vérifie toi-même les chiffres importants avant de conclure.
- En cas de doute, garde la tâche.
